# 환불 시 사용 크레딧 처리 — 타사 실례 비교검토 (2026-07-24)

> 병렬 웹 조사 2트랙(글로벌 크레딧 SaaS / 국내 서비스·법규, 약관 원문 기준) 종합.
> 결론이 약관 제11조 개정(2026-07-24)의 근거임.

|---|---|---|
| **A. 미사용 한정 전액** (지배적) | Shutterstock(EU 14일)·iStock·Depositphotos(30일)·**Adobe Stock(한국 조항: "7일+크레딧 미사용 시 전액")**·ElevenLabs(14일)·**경쟁사 CHECKHC("크레딧 1개 사용=철회권 포기" 명문, CGVU 2026-01-13)** | 기간 내+사용 0건이면 전액, 1건이라도 쓰면 0원 |
| B. 전면 비환불 | OpenAI·Anthropic **API 크레딧**("non-refundable"+1년 만료), ElevenLabs 선불팩 | "All sales are final" + 법정 예외만 |
| C. 사용량 임계값 | Midjourney(**계정 평생 20 GPU분 미만**만 환불, 셀프서브 자동 판정), Runway 구독("close to unused" 재량) | 미만=전액/이상=0, 비례 없음 |

**한국 대응 대기업 선례**: Adobe Stock "한국 거주자 7일+미사용 전액 환불" / Anthropic "한국
거주자 7일 무조건 청약철회" 명문화.

**어뷰즈 방지 표준 장치**: 차지백 시 상당 크레딧 자동 회수(OpenAI Service Credit Terms),
환불 확정 시 즉시 다운그레이드 명문(Runway), 선례 부정 조항(Runway), 정지 계정 환불 배제(공통),
분쟁 중 환불 동결(Anthropic). IAP: Google Voided Purchases API "claw back" /
Apple CONSUMPTION_REQUEST(환불 판정 전 소비량 신고로 기각 유도).

## 3. 국내법 분석 (조문 원문 확인)

1. **전상법 제17조 1항**: 7일 청약철회 배제 불가.
2. **제17조 2항 5호 단서**: **가분적 디지털콘텐츠는 미개시 부분 철회 가능** — 크레딧은
   가분적으로 해석될 여지가 커서 "1크레딧 사용 시 전액 환불 불가"(뤼튼·미리캔버스 방식)는
   7일 내 법적 방어가 약함.
3. **제17조 6항**: 철회 제한의 전제 = 사전 표시 **+** 시험 사용 수단 제공(Free 크레딧이
   역할 가능, 콘진법 제27조 "한시적·일부 이용 가능 조치" 인정). 미조치 시 제한 무효.
4. **방판법 제2조 10호·31·32·52조**: 환급 제한/위약금을 두는 순간 계속거래 → "실공급분
   초과 수령액 환급"이 **편면적 강행규정**(약관 배제 불가).
5. **소비자분쟁해결기준(공정위고시 제2025-14호)** 인터넷콘텐츠업: 중도해지 = 이용일수
   해당액 + 잔여 10% 공제 후 환급, **7일 내 해지는 위약금 없이 이용분만 공제**.
6. **콘텐츠이용자보호지침 제25조 3항**: 할인 약정 해지 시 **단기(정가) 기준 재산정** —
   "사용분 정가 환산 공제"의 규범 근거.
7. **집행 동향**: 2025-10 공정위, 쿠팡·웨이브 등 제재 — **중도해지(잔여 환급) 옵션을
   화면에서 숨긴 것** 자체를 기만적 해지 방해로 제재. 환급 기한 3영업일(전상법 제18조 2항).

## 4. OriPics 채택 산식 (약관 제11조 반영, 2026-07-24)

- **회당 정가 고지**: 1회 인증(공개링크 포함) 정가 = **₩1,000**(VAT 포함) — 요금제
  페이지에 달리 고지 시 그 금액 우선. v2 패스 상품(₩2,900/3건≈967원)과 정합.
- 7일 내 + 전부 미사용 → **전액 환불** (자동 승인)
- 7일 내 + 일부 사용 → 결제액 − (사용 횟수 × 회당 정가), **위약금 없음**
- 7일 후 중도해지 → 결제액 − max(사용분 정가 환산, 경과 일할액) − **잔여분 10%**.
  일반해지(기간말 유지·환불 없음)와 **병행 제공·표시**(공정위 제재 트렌드 대응)
- 무상 크레딧(가입·이벤트·Free) 환불 대상 제외 + 해지 시 소멸
- 산정액 ≤ 0 → 환불 불가
- 환불 확정 시 즉시 다운그레이드 + 차지백 시 상당 크레딧 회수 (어뷰즈 방지)
