- **1차년 현실 목표**: 각 군 상위 2곳 성사(자리톡·직방 / 카모아·공제조합 / 집닥·오늘의집) → 연 ≈2.3억. 확률 가중 전체 기대값 ≈2.0억.
- **먼저 칠 3곳**: ①자리톡(가장 큰 사용자 풀·흑자 스타트업·기능 연동 여지) ②카모아(중소 렌터카 600업체 한 번에·분쭁 명분 명확) ③집닥(집닥맨 현장 사진=바로 적용). 셋 모두 스타트업이라 담당자 1명 미팅으로 결정 가능.
- **협회·조합(공인중개사협회·주택관리사협회·렌터카공제조합·전문건설협회)**은 회원 수는 크지만 6~12개월 걸림 → 스타트업 레퍼런스 확보 후 2027 상반기 접촉.
- **시공군은 매출보다 사용 빈도·PDF 기록서 레퍼런스 확보용**. 단가 상승은 B2B 좌석(집닥맨·하우스텝 직영팀)에서.

## 전제·한계
- 가입률·유료 전환률(30%)은 베타 데이터 없이 SaaS 일반값 적용 — 첫 파트너 파일럿 후 보정.
- 규모 수치 중 '추정' 표기는 공개 집계 없음(집닥 활성 파트너, 직방 직영 중개사, 관리소장 회원 수, 숨고 인테리어 고수).
- 차량당 과금(300~500원/월)은 A-79 이월 금지·충전 표현 금지 원칙과 충돌 없음(구독형 좌석/대수 요금).
