# 용인시 구청 교통과 불법주정차 주민신고 — 방법·운영 기준·통계 조사 (2026-09-07)

> 대표 요청. 공개 자료(용인시 포털·행안부·언론) 기준. 용인시 자체 신고 건수 통계는 공개 자료에 없음 → 정보공개 청구 필요(아래 §5).

## 1. 신고 방법 (전국 공통, 행안부 안전신문고)
- 채널: **안전신문고 앱 → 안전신고 → 불법주정차** (2024년 경찰청 스마트국민제보 통합 → 모든 교통법규 위반은 안전신문고). 시가 앱을 바꿀 수 없는 국가 시스템.
- 사진: **동일 위치·동일 각도에서 1분 이상 간격 2장 이상**, 전면 2장 또는 후면 2장(혼용 불가), 차량번호·위반 장소 식별 필수. **앱 내부 촬영 기능으로만 접수 가능**(갤러리 사진 불가 — 촬영 시각이 앱에 찍혀 단속 자료로 인정). 2023.7.1부터 1분 간격 전국 통일.
- 접수 기한: 촬영일 **익일까지**.
- 처리: 요건 충족 시 **단속 공무원 현장 확인 없이 과태료 부과**(도로교통법 §160③, 시행령 §88). 신고자는 공익신고자 보호법 보호.
- 대상 **6대 구역**: 소화전 5m, 교차로 모퉁이 5m, 버스정류소 10m, 횡단보도, 어린이보호구역(초등학교 정문 앞 등), **인도(2023.7 추가)**. 연혁: 2019.4.17 4대 구역 → 2020.6 어린이보호구역 → 2023.7 인도.
- 지자체 재량: 신고 가능 **시간대·과태료 면제 기준·구역 세부**는 시군구가 정함(행안부 2023.7). 용인시 자체 시간대 제한은 공개 페이지에서 미확인 → 구청 교통과 확인 필요.

## 6. OriPics 관점 정리
- 시민 신고는 **안전신문고 앱 내 촬영이 법적 요건**이라 대체 불가. 진입점은 ① **의견진술·이의신청 분쟁**(연 수십만 건 단속 중 20일 내 진술 — 운전자 측 "그 시각 그 자리에 없었다/이미 이동했다" 원본 사진 증명), ② **단속 공무원·위탁업체 이동 단속 촬영분** 원본 증명(과태료 분쟁 방어), ③ 상가지역 단속 유예·EV 충전구역 등 **시 자체 신고제**(안전신문고 밖) 사진 접수 채널, ④ 앱 유실·기준 상이 문제를 근거로 한 "검증 가능한 사진 접수" 제안.
- 접촉: 구청 교통과 교통지도팀장(단속·의견진술 실무) — 시청 교통정책과보다 구청이 접근 쉬움.

## 7. 보충 — 5분 규칙과 구역 구분 (대표 질문, 9/7)
- 도로교통법 §2: **정차**=운전자 탑승(즉시 운전 가능)·5분 이내 / **주차**=5분 초과 또는 시간 무관하게 운전자가 차를 떠난 상태(승객 대기·화물 적재·고장 포함). "5분 이내"는 탑승 중일 때만 성립 — 편의점에 잠깐 내린 순간 이미 주차.
- 구역별: **주·정차 금지(§32, 황색 복선·실선 — 6대 구역 전부)**=정차도 위반 → 주민신고 1분 간격 근거 / **주차 금지(§33, 황색 점선 — 터널·다리·공사구역·경찰청장 지정)**=5분 이내 정차 허용 / 탄력 구간(황색 실선+보조표지)=지정 시간 외 허용 / 흰색 실선·표시 없음=허용.
- CCTV 재촬영 간격도 절대 금지 1분·주차 금지 5분이 일반 운영(용인 구청별 설정은 확인 필요).
- 의견진술 함의: "5분 이내였다" 소명은 황색 점선·일반 도로에서만 유효. 다툴 땐 도착·출발 시각+탑승 사실을 시각 검증 사진 2장으로 대조.

## 8. 보충 — 의견진술에서 운전자 측 원본 증명이 필요한 이유
- 의견진술=사전통지 후 20일(용인) 내 서면·홈페이지 소명, 구청 교통과 담당자가 **서류만으로 심사**. 시 측 증거=시스템이 시각을 찍은 사진(CCTV·이동단속·주민신고 1분 2장) vs 운전자 측=검증 안 된 사진·진술 → 비대칭.
- 인용 사유 대부분이 시각·위치 문제: 응급·고장 부득이 정차, 탑승 5분 이내, 표지·노면표시 부재, 이미 이동, 유예 시간대(점심·상가 19~21시), 장소 불일치, 장애인 표지.
- 일반 폰 사진이 약한 이유: EXIF 편집 가능(사후 촬영 의심 반박 불가), 카톡·메일 전송 시 압축으로 EXIF 소실, "확인 불가" 기각.
- OriPics 사진: 셔터 순간 시각·GPS·기기 검증이 픽셀에 새겨지고 공개링크로 심사자가 앱 없이 확인 → 시 측 증거와 동급의 시각 신뢰. 활용 장면: 고장 시 삼각대·보닛 사진, 가려진 표지판·지워진 노면 사진, 유예 시간대 위치·시계 사진, 주민신고 2장 사이 출발 사진.
- 한계: **사건 순간에 찍은 사진만 효력**(통지 후 재방문 촬영은 무효), 증거 능력 판단은 기관, 시가 이미 아는 사유(표지 부재·유예)는 사진 없이도 인용 가능. 결정적인 경우="그 시각 그 자리에 있었나"가 쟁점일 때.
- 시장 의미: 용인 단속 연 20만 건대(2017 22만)·전국 주민신고 2024 ≈800만 → 의견진술 중 "증명 못 해 지는" 건이 연 수만 건. 렌터카(과태료 차량 명의→이용자 전가, 인수·반납 시각 증명=비용)·임대관리·시공(현장 정차 잦음) = 기존 Pro 타깃 3직군과 정확히 겹침. 구청 입장에서도 검증 가능 사진=심사 단축·민원 재반복 감소 → "이의신청 시 원본 검증 무상 지원" 제안 근거.

## 9. 보충 — 단속 공무원·위탁업체 이동 단속 촬영분의 실제 구조
**(1) 차량탑재형(자동)**: 단속차 지붕 카메라+번호판 인식(LPR)+GPS. 구간 서행 시 자동 촬영·인식·시각·좌표 기록 → 일정 시간 뒤(절대 금지 1분·주차 금지 5분 이상) 재순회 재촬영, 2회 모두 같은 자리면 위반 자동 등록. 사람은 운전+사후 검수(오독·가림·이륜차).
**(2) 단속원 휴대 단속(사람 촬영)**: 개인 폰 아님 — 구청 지급 **단속 전용 단말(PDA형/업무용 스마트폰+단속 앱)**이 시각·GPS·단속원 ID를 자동 부착하고 번호판 인식 후 서버 즉시 전송. 위반 차량에 과태료 부과 대상 표지(스티커) 부착 → 부착일이 의견진술 20일 기산점. 탑승 시 계도 후 5분 초과 단속, 부재 시 즉시. 내부 기준: 번호판·차량 전체·위반 표시(노면·표지판·소화전)가 한 화면, 2장 이상. 인력=구청 교통지도팀 기간제·공무직(일부 지자체 공단·민간 위탁; 용인 위탁 여부는 구청 확인), CCTV·알림 시스템 유지관리=위즈샷 등 업체.
**(3) 촬영 이후 경로**: ①단말→구청 주정차단속시스템 서버 즉시 전송(개인 기기 미보관 원칙, 임의 삭제·수정 차단) ②번호판 인식→자동차등록원부 연계 소유자 조회→관제 육안 검수(오인식·중복·면제: 장애인 표지·긴급차량·유예 시간) ③사전통지서 우편(사진·시각·장소 인쇄), 본인은 홈페이지 단속정보조회로 사진 열람 ④20일 후 과태료 부과→위택스 조회·납부(자진 20% 감경, 미납 가산금·압류) ⑤보존: 비위반 일반 영상=개인영상정보 방침상 보통 30일 내 삭제 / 위반 확정 사진=과태료 부과 근거로 부과 기록과 함께 보존(이의신청·행정소송 증거), 정보주체 열람·삭제 요구 시 10일 내 회신.
**(4) OriPics 자리**: 자동 촬영분은 불필요. 휴대 단속분은 "구청 시스템이니 믿는다"는 전제 → 조작·시각 다툼 시 제3자 검증 수단 부재 → 시 측 방어 자료. **가장 큰 틈=단속 시스템 밖 사진**: 견인 전후 상태, 표지 부착 장면, 계도 상황, 단속원이 개인 폰으로 찍어 메신저로 넘기는 보조 사진 — 관리 경로 없음 → **시 전용 비공개 사서함으로 접수+원본 증명**이 구청 교통과 제안의 구체 지점. 운전자 측은 정차 순간 촬영만 유효 → 렌터카·시공·임대 사용자에게 "현장 정차 시 한 장" 습관 안내.
