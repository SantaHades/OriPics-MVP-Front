1. 공인중개사·임대관리 — 입주/퇴실 상태 증빙
2. 중고차 딜러·정비·렌터카 — 인수/반납 상태
3. 건설·인테리어 시공 관리자 — 시공 전후 기록
4. 보험설계사·손해사정사 — 사고 현장
5. 사진작가·일러스트레이터 — 원본·창작 시점

경로: A) 지인 스노볼(직군 지인→동료 소개) B) 네이버 카페·오픈카톡(홍보 규정 확인). 유료 테스터 대행 금지(2026 Google 실사용 검증 + 피드백 무가치).

운영: 참여 확정 → 이메일 internal 목록 추가 → 참여 링크 → 온보딩 안내문 발송 → Pro 수동 부여 → 테스터 오픈카톡방 운영(7일차 리마인드 1회). 12명 옵트인 확인일 = 14일 카운트 시작.

## 2. 카페/커뮤니티용 모집글

(본문 — 직군 카페별 도입부 교체)

```
[베타 테스터 모집] "그 사진, 조작한 거 아니에요?" — 사진 원본 증명 앱 OriPics

안녕하세요. 사진 원본 증명 서비스를 만들고 있는 스타트업 산타하데스입니다.

퇴실 정산 때 입주 당시 사진을 내밀어도 "그거 나중에 찍은 거 아니냐",
"보정한 거 아니냐"는 말 한마디면 증거 가치가 흔들립니다.
사진은 넘치는데, '원본'임을 증명할 방법이 없기 때문입니다.

OriPics는 촬영하는 순간 사진에 보이지 않는 디지털 지문과
촬영 시각·GPS 좌표를 새기고 서버가 서명합니다.
픽셀 하나만 바뀌어도 감지되고, 공개링크 하나로
상대방·보험사·법원 누구에게나 원본임을 보여줄 수 있습니다.
Adobe·Microsoft·Sony가 만든 국제 표준 C2PA의 적합성 인증(Conformant) 제품입니다.

정식 출시 전, 현장에서 사진으로 증빙할 일이 많은 분들의
목소리를 듣고 싶어 베타 테스터를 모십니다.

■ 이런 분을 찾습니다
- 임대·중개 업무로 입주/퇴실 상태 사진을 찍으시는 분
- 차량 인수·반납·정비 전후 상태를 기록하시는 분
- 시공 전/중/후 현장 사진으로 하자 분쟁을 겪어보신 분
- 작품 도용 때문에 원본 증명이 필요하신 분

■ 참여 조건
- 안드로이드 폰 사용자 (Google 계정 필요)
- 2주간 평소 업무에서 찍던 사진을 OriPics로 몇 장 찍어보고
  불편한 점을 알려주실 수 있는 분

■ 혜택
- 베타 기간 Pro 플랜 무료 제공 (월 1,000회 인증 · 영구 보관 · 촬영 검증)
- 개선 요청 최우선 반영 — 베타 중 여러분 의견이 곧 로드맵이 됩니다

■ 참여 방법
댓글 또는 hi@ori.pics 로 Gmail 주소를 보내주시면
초대 링크를 보내드립니다. (선착순 20명)

서비스 소개: https://www.ori.pics
```

도입부 교체안:
- 차량: "탁송 인수 때 멀쩡했던 차가 '원래 흠집 있었다'는 말로 돌아온 경험, 있으시죠. 인수 시점 사진을 찍어둬도 '그 사진 언제 찍은 건데요'라는 말 앞에선 소용이 없습니다."
- 시공: "준공 때 분명히 찍어둔 사진인데, 하자 접수가 들어오면 '시공 직후 사진이 맞긴 하냐'부터 다툽니다. 날짜도 위치도 증명이 안 되니까요."
