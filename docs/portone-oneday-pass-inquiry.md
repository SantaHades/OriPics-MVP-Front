| 항목 | 내용 |
|---|---|
| 상품명 | 원데이 패스 (선물 가능 1일 이용권) |
| 가격 | 3,300원 (VAT 포함) 단건 결제 |
| 내용 | 당사 서비스(OriPics) 내 사진 촬영 인증 10회 + 인증서 PDF, 등록 시점부터 24시간 유효 |

- 당사 단일 서비스 전용 이용권으로, 타 가맹점 사용·현금 환급·잔액 이전이 불가
  하여 선불전자지급수단(전자금융거래법)에 해당하지 않음
- "상품권·쿠폰·충전" 명칭을 사용하지 않고 "이용권(패스)"으로 판매
- 재판매 금지·전용 사용 약관 명시

1. 상품권류 고위험 업종으로 분류되어 별도 심사·카드 결제 제한이 발생하는지

3. 필요한 추가 심사·서류가 있는지
